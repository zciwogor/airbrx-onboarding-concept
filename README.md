# Airbrx onboarding concept

A clickable concept prototype by Adam Rogowicz proposing an onboarding flow for Airbrx: Sign up, Connect, Point your tool, See the value (a live traffic simulator).

**Not the official Airbrx site.** Everything is simulated in the browser. Nothing you type is submitted or stored. Power BI and Tableau screens are illustrative mock-ups, not the real products. Simulator results, savings figures and pricing are placeholders, not quotes.

View it at https://zciwogor.github.io/airbrx-onboarding-concept/

Product docs hub (pricing, GTM plan, PRD, evangelist guide, with PDFs, revision log and comments): https://zciwogor.github.io/airbrx-onboarding-concept/docs/

Bill-language value calculator (Snowflake, Databricks, Postgres): https://zciwogor.github.io/airbrx-onboarding-concept/calculator/
