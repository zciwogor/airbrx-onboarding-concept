# AiRBRX onboarding concept

A clickable concept prototype by Adam Rogowicz proposing an onboarding flow for AiRBRX: Sign up, Connect, Point your tool, See your savings.

**Not the official AiRBRX site.** Everything is simulated in the browser. Nothing you type is submitted or stored. Power BI and Tableau screens are illustrative mock-ups, not the real products. Savings figures and pricing are placeholders, not quotes.

View it at https://zciwogor.github.io/airbrx-onboarding-concept/

Bill-language value calculator (Snowflake, Databricks, Postgres): https://zciwogor.github.io/airbrx-onboarding-concept/calculator/
